# UEBridge 0.19.0：再照明とNiagara水源の連携

MODは **0.18.0** のまま、UE専用の累積更新です。0.18.6で利用者が確認した安定100fpsを基準に、通常表示の固定、黒い面につながる再照明処理、水用アセットの連携を変更しました。水の最終的な写実表現は実機での調整が残っています。

## 導入

1. UEを終了して既存のUEBridgeフォルダーをバックアップします。
2. [UEBridge-update-0.19.0.zip](https://github.com/TSUNAMI-SMP/UE-MINECRAFT/raw/refs/heads/ue-native-play-0.15.0/downloads/UEBridge-update-0.19.0.zip) を展開し、中身を既存の `unreal\UEBridge` に上書きします。ContentとSavedは保持します。
3. そのフォルダーでPowerShellを開き、実行します。

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File ".\Play-Native.ps1" -Rebuild -Reimport
```

現在の `native_manifest.json` を使用します。**今回は水用アセットの準備があるため、再ビルドと再取り込みの両方が必要です。** MOD 0.18.0の書き出しは継続できます。起動ログの `Bridge UE 0.19.0 / MOD 0.18.0` が新版の目印です。

## 変更

- 再照明：地形再構築が処理時間を使い切っても光の更新が進むよう、再照明へ独立した約2ms／最大8セルの予算を割り当てました。初期光の伝播完了後にも表示中のセルを再照明します。黒い面の実機での解消は未確認です。
- 通常表示：Lighting ON、影OFF、従来の全体リアル表示OFFに固定します。旧セーブの切替設定を引き継がず、メニューの3つの切替とF6の照明切替を除去します。F3・F5のUEデバッグ入力競合修正は継続しています。
- 専用の水：無料Niagara Fluidsの `Grid3D_FLIP_Hose` を水用システムへ複製する取り込みと、水源の設置・回収・保存・再開・削除・取り消しを接続しました。最大2水源、各10×10×8ブロック、32ブロックより遠ければ停止します。アセットや必須の領域制御がなければ設置を拒否し、バケツを保持します。

アセットの準備、テンプレート互換性、制限と確認方法は同梱の **[NIAGARA_WATER.md](NIAGARA_WATER.md)** を参照してください。水の素材・泡・しぶき・地形衝突はインストール済みアセットの設定に依存し、このクラウド環境では未検証です。UEアセットのバイナリは更新ZIPに含めていません。

新しいGPU水には泳ぎ・溶岩反応・オフライン動画記録を接続していません。水源がある間は記録開始を拒否します。従来の砂・TNT・溶岩を今回すべてアセット表現へ移行したわけではありません。

独立C++・Python・PowerShellの検証は成功しています。Windows UE 5.8.3のビルドと実描画は未実行で、水源を置いた場合のFPSと写実品質は未保証です。
