- `test_native_*.py`：57件成功。UI・素材取り込み、独立C++ヘルパー、符号付き視点と戦闘、PowerShellを含む既存の回帰確認。
- `test_realistic_physics.py`：2件成功。本番の物理ヘッダーをC++17・警告をエラー扱いでコンパイル。小数原点／負座標での1マスの注水、物理占有と隣接面の判定、未着火TNTの固定、砂の広がり・接地・支持除去、液体量の保存、回収・反応・飛沫、導火線・連鎖爆発、個数上限、種類と範囲による削除を確認。AVIのffprobe／ffmpeg検証も成功。
- `test_voxel_index.py`：1件成功。全512マスに対し、衝突用行と重複する表示行を含む従来の走査結果と一致。境界外・再構築後の行番号も確認。
- `test_realistic_materials.py`：1件成功。14種のグラフ生成・保存・再利用、画像サンプル不使用、RGB／alphaの明示分離、水の屈折・法線入力をモックで検証。GPUシェーダーをコンパイルした結果ではありません。

- `test_native_build_plugins.ps1`：成功。Niagara Fluidsがある場合だけ有効化し、既存設定とユーザープラグインを保持。再実行も確認。
- 独立C++の光・空・メッシュ・ネイティブ表示計算の回帰確認。
- Python構文・差分の空白、更新ZIPのCRC・重複エントリー・全ソース／ヘルパー一致・SHA-256確認。

## 追加したが、この環境では未実行のUEテスト

`BridgeWorldTests.cpp` に負のマスと破壊後の行番号更新を追加。`BridgeRealisticTests.cpp` に小数格子原点の保存復元と旧形式の量を保つ移行を追加しました。UEのAPIを含むため、独立C++検証と区別しています。独立C++では旧格子の移し替えが一対一となり、各軸の補正が12.5cm以内であることを検証しています。

Windows UE 5.8.3のビルド・衝突・素材コンパイル・Niagara再生・GPU描画・音と実FPSは未検証です。Niagaraの名前・System型・Userパラメーターはインストール内容に依存します。未検出時の代替をNiagara使用済みとは扱いません。

FPS対策はコード上の不要な走査と更新を減らしたものです。ユーザー環境の低下原因の確定や、改善後の30／60fps等の数値はまだ測定できていません。各CPU時間とUEのGame／Draw／GPU時間を比較する必要があります。

液体は25cm有限格子、砂は512衝突用粒子／個の近似です。水面法線や細粒描画は細かくしていますが、動画の流体精度や全砂粒の独立計算を実装したものではありません。
