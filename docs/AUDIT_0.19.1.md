# 0.19.1 検証記録

2026-10-09。利用者のUE 5.8.3ビルドログで `BridgeRealisticWorld.cpp` の `auto* Pawn=PC->GetPawn()` がC3535／C2440で停止することを確認しました。戻り値は `TObjectPtr<APawn>`。水用Niagaraファイルを含む他のコンパイル処理には、このログで追加のエラーは報告されていません。全体のリンク・ビルド完了はしていません。

当該変数を `auto Pawn` に変更。これで戻り値のポインター表現を保持してbool判定・メンバーアクセスを行い、旧版の生ポインターにも対応します。同じ直接的な `auto* = GetPawn()` を他のソースで使用していないことを確認しました。起動版表記を0.19.1に更新しました。

独立ネイティブ検証59件は成功、スキップなし。更新ZIPのCRC・全ソース111ファイル／ランチャー8本／Pythonヘルパー15本の内容一致とSHA-256を検証しました。今回の変更でUEの返却型そのものを独立テストで代用してはいません。

修正後のWindows UE 5.8.3コンパイル・リンク・取り込み・実描画は未実行です。0.19.0の水源連携と写実表現の未検証・未完成範囲は [NIAGARA_WATER.md](NIAGARA_WATER.md) のとおりです。
