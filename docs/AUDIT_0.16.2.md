# 0.16.2 検証記録

2026-10-09（日本時間）。提供されたUEBridge.logとCrashContext.runtime-xmlから、ゲームがNativePlayを開いた後、地形読み込み中に停止したことを確認しました。

スタックの先頭は `ABridgeBlockPreview::Replace`、次が `ABridgeWorld::RebuildCell`、`Handle`、`FBridgeNativeWorldStore::Tick` です。AssertionはArray.hのCheckAddress、要素サイズ4、要素数6でした。裏面のインデックス追加処理と一致しています。メモリー不足やGPUドライバー障害と診断する根拠はありません。

実行コードの変更はBridgeBlockPreview.cppの1ファイルです。配列内部の要素参照を直接Addへ渡す処理を、先に値をコピーしてから追加する処理へ置き換えました。
