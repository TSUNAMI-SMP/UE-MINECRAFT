# 0.14.0 修正・検証記録

0.13.2を基点に、利用者が報告した14項目を実装修正しました。旧配布物・ブランチ・保存は保持します。全変更を揃える前の更新ZIPは出力しません。

## 修正対応

| # | 問題 | 今回の変更 |
| --- | --- | --- |
| 1 | 照明ONの時刻と光が不自然 | ON/OFFで同じMinecraft環境を使用。固定されたUEの空・光源をnative中は退避し、書き出した太陽／月の方向・skyFactor・雨で直接光を設定。露出の自動変更、UEの霧と反射を抑え、光マップを環境光として使用。native終了時は元へ戻す |
| 2 | 羊毛がない | Fabricで成人／子羊の羊毛モデルを取得し、歩行ポーズも書き出す。利用者のアクティブパックの羊毛画像を染色し、胴体画像とローカルで合成。刈られた羊には追加しない |
| 3 | SAVEで操作停止 | 保存開始時に地形・プレイヤー・所持品・モブ・落下物・TNTをスナップショット化。書き込みは1msを目安にセル単位で進め、全世界のポーズ・入力停止を撤去。終了時は進行中の保存を完了してから最新状態も保存。原子的置換は維持 |
| 4 | 感度を設定できない | Escメニューに減少／増加を追加。0～200%を5%ずつ調整し、NativeControls.iniで再起動後も保持 |
| 5 | インベントリ未完成・管理画面が開けない | 256pxの画像全体を縮小していた表示を正しいパネル領域に変更。高解像度パックでも論理UVを使用。検索Widgetの余白がクリックを奪う処理を修正し、所持品タブを検索欄から離す。クリックを入力イベントで処理 |
| 6 | アイテム・ブロックが平坦 | Minecraft 1.21.11のGUI拡散光の方向と係数でアイコンの各面を陰影処理。既存のモデル形状・GUI変換・UV・色・透明度を保持。手持ちには光マップの面方向による濃淡とnative直接光を使用。原因を「影がない」だけと断定しない |
| 7 | 三人称にならない | 視点割り当てのキー押下をInputKeyで処理し、一／後方三／前方三人称を即時適用。ポーズメニューからも変更可能 |
| 8 | クリエイティブの慣性がない | 飛行の水平.91／垂直.6のtick減衰と入力加速を専用移動コンポーネントで積分。衝突はUEのsweepとslideを使用。入力解除時に急停止しない。上下入力は水平入力と独立し、上下速度はダッシュで倍増しない |
| 9 | 敵が被ダメージで赤くならない | 共有材質へ赤色オーバーレイを追加し、個々のモブの動的材質で10tickだけ有効にする |
| 10 | 敵の無敵時間がない | 最初の10tickは同等以下のダメージを拒否し、強い攻撃は前回との差分を適用。差分攻撃でタイマーを延長しない。無敵時間中のモブの奥を採掘しない |
| 11 | 死亡した敵が空中に浮く | 倒れる曲線を変更し、描画中の全パーツの最低位置を床に合わせる。カプセル中心で横倒しにしていた浮きを補正。20tickで削除 |
| 12 | 武器にクールダウンがない | MODで実際のメインハンド攻撃属性を保存し、攻撃速度に応じた回復と威力 `.2+.8*charge²` を適用。アイテム交換／空振りでも回復をリセット。クリックと長押し採掘を分け、照準下に回復バー |
| 13 | 敵の速度と歩行が違う | エクスポートした速度属性を使用し、徘徊と追跡を分ける。実移動量から歩行強度を計算し、.4/tickの補間と子供の位相倍率を反映。移動量が常に0になっていた更新順序を修正 |
| 14 | ノックバックが違う | 基本強度0.4 block/tick、既存速度の半減、接地時の上方向の上限を反映。書き出した抵抗属性を適用。地上と空中の減衰を調整 |

## 実行した検証

- Minecraft 1.21.11／Yarn build.6／Java 21でFabric MODの `test build`。羊毛モデル・部品・属性のAPIを実コンパイル。Javaテスト194件、失敗0。
- bridgeのPython回帰テスト108件。画像・モデル・音・材質・ステージング・失敗時の復元・ローカル通信を確認。
- native setup 19件（Windows固有の1件はLinuxでskip）、UI検証15件、world-format検証5件。
- UEから独立したC++本番ヘルパーを警告をエラーとしてコンパイル。攻撃回復、強い攻撃の差分受付、20Hzの飛行参照計算、30／60／120／144fpsでの速度・距離を照合。既存の照明、太陽／月、キャラクター、モブ生成の計算も確認。
- ローカルのMinecraftクライアントJARから1008ブロックIDを一時書き出しし、モデル・画像・チェックサムを検証。抽出した画像は配布しない。
- PowerShellで取り込み失敗表示、ソース更新検出、終了コード／完了ログ照合、ランチャー構文、Buildプラグイン設定保持のfixtureテスト。
- 新しいUE自動テスト `UEBridge.Native.Mobs.HurtWindowAndGroundedDeath` を追加。実モブの初期化、同等／弱い／強い攻撃、死亡時の描画境界、専用移動コンポーネントを確認する内容。クラウドでは未実行。
- 最終ZIPのCRC、収録ソースと最終ツリー、MODのバージョン、SHA-256を確認して配布する。

## 確認できない範囲

クラウドにはWindows UE 5.8.3・RTX 5060のゲーム画面がありません。**今回のUEコンパイル、シェーダーコンパイル、クリック／IME／視点の実操作、明るさと影の調整結果、ノックバックの実距離、保存時の実フレーム時間は未確認です。** Pythonの材質fixtureはUEシェーダーをコンパイルするテストではありません。追加UEテストも実機での実行が必要です。

照明は書き出し時刻のスナップショットです。Minecraftとの時刻のライブ同期、UE側だけの昼夜進行は追加しません。照明ONの直接光の強さは初期調整値で、実際のスクリーンショットによる評価が必要です。

通常の近接攻撃を対象にした修正です。AI全体・全モブの固有行動、武器のエンチャント・クリティカル・特殊効果・ダッシュ追加ノックバックを原作と完全一致させる変更ではありません。クラフトと防具の装備UIも未対応です。死亡の接地補正は描画境界を用いるため、凹凸のある床や特殊形状は実機確認が必要です。

保存時はコピーとファイル同期を行います。長時間の操作禁止は取り除きましたが、大規模な保存や遅いディスクで処理時間がゼロになる保証はありません。新書き出しは新しい保存IDです。旧UE保存の編集結果を別IDへ移植する機能はありません。
