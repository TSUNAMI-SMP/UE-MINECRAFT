# UEBridge 0.17.0 更新手順

Minecraftを書き出しにだけ使い、UE単独で描画・操作・クラフト・ワールド更新・保存する版です。0.16.1／0.16.2のコンパイル・裏面追加クラッシュ修正も含みます。Minecraftサーバーの常駐は不要です。

- [MOD 0.17.0](https://github.com/TSUNAMI-SMP/UE-MINECRAFT/raw/refs/heads/ue-native-play-0.15.0/downloads/minecraft-ue-bridge-0.17.0.jar)
- [既存UEBridge用更新ZIP](https://github.com/TSUNAMI-SMP/UE-MINECRAFT/raw/refs/heads/ue-native-play-0.15.0/downloads/UEBridge-update-0.17.0.zip)
- [初回用ソース＋MOD一式](https://github.com/TSUNAMI-SMP/UE-MINECRAFT/raw/refs/heads/ue-native-play-0.15.0/downloads/UE-Minecraft-MVP-0.17.0.zip)
- [検証記録](AUDIT_0.17.0.md)

## 適用

1. UEとMinecraftを終了します。旧UEBridge MODをmodsフォルダーから外し、0.17.0 JARに交換します。
2. Minecraft Java 1.21.11でシングルプレイを開き、`/uebridge native export` を実行します。今回追加したレシピ・燃料・コンテナ・防具・モブ追加描画層が必要なため、**新しい書き出しが必要**です。
3. UE更新ZIPの全内容を、使用中の `UEBridge.uproject` があるフォルダーへ上書きします。Source・Pythonヘルパー・起動スクリプトをすべて更新してください。既存のContent／Savedを削除する必要はありません。
4. 同じフォルダーでPowerShellを開き、次を実行します。ファイル選択画面では、手順2で新しく生成された `native_manifest.json` を選びます。

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File ".\Play-Native.ps1" -Rebuild -Reimport
```

最初はC++ビルドと素材の再取り込みを行います。次回からは `Play-Native.cmd` で再開できます。書き出し後はMinecraftを終了して構いません。

新しい書き出しは別のパッケージ識別子です。以前の `Saved/NativeWorlds` と書き出しフォルダーを残してください。以前のUE編集状態を別の書き出しへ自動移行する仕組みはありません。

## 今回の実装

| 報告・要求 | 変更 |
| --- | --- |
| 手持ちアイテムのブラー、地形が腕の前に出る | 一人称の腕・両手を地形とは別のGPU描画で合成。モーションブラー・時間方向AAを無効化。地形の深度で手を隠さない |
| 銅鉱石などの色、屋根下の強い影 | 既定をMinecraftの光マップと面の拡散光へ変更。古い保存のUE照明ON設定を移行。F6でUE照明を選べる |
| 村人の服など | 元のFeatureRendererを実行し、服・職業・羊毛・首輪・装備などの追加モデルとテクスチャを記録 |
| インベントリ中に落下が遅い | メニュー中に毎フレーム速度を消す処理を撤去。入力を止め、重力を継続。かまど・回路も継続 |
| 草の変化、砂の落下、花の支持 | 20 tick/秒の近傍更新とrandomTickSpeedを導入。遮蔽した草の土化・周囲への伝播、砂・砂利・コンクリートパウダー・金床の重力、支持を失った植物の脱落 |
| 石切台などのアニメーション | 元のmcmetaのフレーム順・時間・RGB補間を保持。長いプリズマリン補間はシェーダーで処理 |
| アイテムの光沢 | 手持ち・アイコン・防具へアニメーションするglintを追加。エンチャント金リンゴなど既定スタックの光沢を取得 |
| 装備 | 装備枠と右クリック装備、防御値・耐性、三人称とインベントリ内の防具描画。元のequipment定義とテクスチャを取得 |
| クラフト | 書き出し時の実レシピ・解決済み材料タグ・返却アイテムを取得。2×2／作業台3×3、配置の移動・左右反転、定形・不定形、Shift取り出し |
| 機能ブロック | 作業台・かまど・溶鉱炉・燻製器・石切台・チェスト・樽・ホッパー・ドロッパー・ディスペンサーの素材を使った画面。精錬時間・燃料・進行表示と保存 |
| レッドストーン | ワイヤー0～15、レバー・ボタン・感圧板、トーチ、リピーターの遅延とロック、コンパレーター、オブザーバー、ランプ、ドア類、通常／粘着ピストンの基本動作 |
| アイテムの搬送 | ホッパーの方向・8 tick転送間隔・給電停止・地面の投下物回収、かまどの面別投入／取り出し、ドロッパーの4 tick遅延とランダム枠排出 |
| 検索欄が左上に浮く | 枠付きSlateテキストボックスを検索に使わず、文字・カーソルを既存HUD内へ描画 |
| 着火済みTNT | TNTモデルが重力・抵抗・床の反発で移動し、煙・終盤の点滅と膨張を表示。導火線・位置・速度を保存 |
| 白いクリティカル粒子 | 元の粒子画像・フレーム順、灰色と経時色変化、光マップを使用 |
| 液体テクスチャ | 静止／流動の元画像・フレーム時間・アルファを使用。側面UVと流れ方向のUVを修正。アニメーション設定の上書き消失も修正 |
| ノックバック | MCが地上でも保持する下向き速度を再現し、通常攻撃とダッシュ追加攻撃を順に計算。静止・接地の通常攻撃は上向き0.3608ブロック/tick、ダッシュ追加後は上限0.4。空中の追撃は別計算 |

収納・精錬・クラフト途中・装備・落下中ブロック・TNTはUEのワールド保存に含まれます。搬送や排出、クラフト、ピストンの失敗時に途中まで数量を変えない処理を追加しました。

## 操作と確認

- E：インベントリ。右クリック：機能ブロックを開く／装備。Shift右クリックは設置を優先します。
- F5：視点。F6：照明。T／/：ローカルチャット。Q／Ctrl+Q：投下。
- クラフトは材料枠に置き、結果枠を左クリック。Shiftクリックで所持品へ入れます。石切台では候補を選んで結果を取ります。

Windowsでは次を確認してください。今回のUE C++コンパイル・シェーダーコンパイル・実画面・入力・実FPSはクラウドで未検証です。

1. 一人称で剣とブロックを持ち壁へ接近し、地形との重なり・ブラー・左右の手・F5を確認。
2. 村人のバイオーム服・職業、羊毛と首輪、水／溶岩と石切台のアニメーションを確認。
3. 落下中にEを開き、メニューを閉じた場合と落下を比較。検索文字が検索枠に収まるか確認。
4. 作業台・かまど・石切台・収納・装備を操作し、材料／結果／燃料の数量、保存・再開を確認。
5. レバー→ワイヤー→ランプ、リピーター、コンパレーター、オブザーバー、ピストン、チェスト→ホッパー→かまどを確認。
6. 草の土化／伝播はランダム更新で待ち時間が変わります。砂の支持を壊し、花の土台を壊して保存・再開も確認。
7. 平地の通常・ダッシュ・落下クリティカル・空中追撃と死亡、TNTの落下と煙を確認。

失敗時は `Saved/Logs/NativeImport-*.log` と `Saved/Logs/UEBridge.log` を保持します。

## 残る機能

バニラMinecraft全体の完全移植は完成していません。今回の各機能にも次の制限があります。

- アイテムはID・数量が基本です。任意のData Components／NBT、耐久値、エンチャント効果、個別の染色・装飾・名前、これらを使う動的特殊レシピは未対応。既定スタックの光沢と装備表示は追加しています。
- ディスペンサーは収納画面までです。矢・バケツなどの個別発射挙動、準接続、粘着ブロックの連結移動、ピストンによるエンティティ押し出し、全回路の更新順・トーチ焼き切れは残っています。
- ラージチェスト結合、エンチャント台・金床・醸造台・鍛冶台・取引などの専用画面、精錬経験値、全戦利品表・全作物の成長は未完成です。
- 水・溶岩の描画は改善していますが、全流体規則、気泡柱、全モブ固有AI、すべての特殊モデル・粒子・TNT爆発耐性の完全一致は未完成です。
- モブ追加層は元のrendererを記録しますが、実ゲーム内での全種類・全個体の取得とUE表示は未検証です。

MinecraftのゲームJAR・原作ソース・画像は配布物へ含めず、利用者の環境から書き出します。
